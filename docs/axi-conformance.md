# AXI conformance

Where `llm-semantic` stands against the ten principles on [axi.md](https://axi.md). This table is the current record; [axi-audit.md](axi-audit.md) is the snapshot it replaced.

| # | Principle | Status | Notes |
|---|---|---|---|
| 1 | Token-efficient output (TOON) | Met | TOON is the default output of every command. `--json` (JSON) and `--plain` (human-readable text) each replace it; `--axi` is still accepted and changes nothing. Contradictory format flags (`--plain --json`, or `--min` with `--plain`) exit 2. |
| 2 | Minimal default schemas (3-4 fields per item) | Met | A default search row carries four fields (`file` as `path:line`, `name`, `score`, `content`); `memory search` carries `id`, `question`, `score`, `answer`. `--full` opts back into every field. |
| 3 | Content truncation with a size hint and `--full` | Met | The default output cuts content over 200 characters and says how many were left out. `--full` returns the whole text. |
| 4 | Pre-computed aggregates, always a total | Met | The search family states its `total` (`N results for "query"` under `--plain`); `multisearch` reports `total_queries` and `total_results`. |
| 5 | Definitive empty states | Met | An empty search says it found nothing (`message`, and `--plain` says so in text), and a search over an index with no chunks says the index is empty instead (`status: index_empty` vs `no_match`). `callers`/`refs` distinguish `symbol not indexed`, `not indexed for edges` and a genuine empty answer (see [languages.md](languages.md)). |
| 6 | Structured errors on stdout, exit 0/1, idempotent, never prompt | Met | Every error goes to stdout in the active format: a TOON or JSON object with `error: true`, or `Error: ...` under `--plain`. stderr carries only diagnostics. A failure exits 1; an unknown flag or command, a missing argument or contradictory format flags exit 2 and name what was wrong, as axi.md asks ("unknown flags must fail loud"). No command prompts: `collection delete` without `--force` and `memory stats --prune` without `--yes` refuse with an error naming the flag and exit 1, deleting nothing. |
| 7 | Ambient context (`setup` command, Agent Skill) | Met | `llm-semantic setup` registers a SessionStart hook with Claude Code (`.claude/settings.json`) and Codex (`.codex/hooks.json`, with `[features] hooks = true` in `.codex/config.toml`), and an OpenCode plugin (`.opencode/plugins/llm-semantic.ts`) acting on `session.created`. Each runs `llm-semantic index-status`, its exit status ignored, so a session starts with this directory's index status and a project with no index raises no hook error. `--target` narrows to one agent. `setup` also writes the Agent Skill to `.claude/skills/llm-semantic/`, and `npx skills add` installs the same skill for other agents, without a hook. |
| 8 | Content first (no-argument run shows live data) | Met | A bare `llm-semantic` prints a description, the executable path and the index status for the current directory. In an unindexed directory it states `status: not_indexed`, suggests `llm-semantic index .` as the next step and exits 0. |
| 9 | Contextual disclosure (`help[]` next steps) | Met | The default output of the search family, `memory search`, `multisearch`, `index-status` and the bare run carries a `help` list of suggested next steps, as do the missing-index error and the unknown-flag, unknown-command and format-conflict errors. |
| 10 | Consistent `--help` on every subcommand | Met | `--help` exits 0 on every subcommand, and an unknown flag or command names it, lists the valid choices and exits 2. The root `-v`/`-V`/`--version` print the bare version and exit 0 on both binaries (a subcommand's `-v` keeps its own meaning, e.g. `index --verbose`). |

Scope note for rows 2-5: they are met in the default TOON output (and `--plain`, where the note says so). `--json` keeps its pre-AXI schema so existing scripts keep working — full fields, untruncated content, and a bare result array without `total` or a zero-result message — so the machine-readable JSON mode does not meet principles 2-5 and is a standing exception with that reason. It is opt-in: nothing prints it unless `--json` is passed.
